# Адаптивный тренажёр ПДД с ИИ

Интерактивное веб-приложение для подготовки к экзамену по правилам дорожного движения. Программа анализирует ответы и подбирает вопросы из слабых тем пользователя.

## Возможности

- Адаптивный подбор вопросов по слабым темам
- Разбор каждого ответа: теория, мера наказания по КоАП РФ, реальная ситуация, практика
- Таймер 30 секунд с цветовой индикацией
- Счётчик серии правильных ответов и прогресс-бар
- Светлая и тёмная темы
- Режим "Работа над ошибками"
- Экспорт отчёта в JSON

## Содержание

5 тем: Знаки, Скорость, Разметка, Обгон, Пешеходы.
12 вопросов с полным разбором и ссылками на статьи КоАП РФ и УК РФ.

## Как работает ИИ

Программа ведёт статистику по темам и находит ту, где процент правильных ответов минимальный (минимум 2 ответа). Следующий вопрос берётся из этой темы. Это адаптивный алгоритм на основе статистики, а не нейросеть.

## Технологии

HTML5, CSS3, JavaScript (ES6+). Без внешних библиотек.

## Совместимость

Chrome, Firefox, Safari, Edge, мобильные браузеры.
